# 기존 제공기관 문의 초안의 Stage 4 보완 — 미발송

기존 문의 본문을 다시 작성하지 않는다. 원본은 PR21의
[issue2_provider_inquiry_draft.md](https://github.com/yj2trigger/sign-language-recognition/blob/f72a44a6929efd4c8ec9a72a71a523aa96f9662b/docs/issue2_provider_inquiry_draft.md)다.
아래 항목만 기존 초안에 추가해 검토한다. 이메일·폼·파일 전송은 수행하지 않았다.

1. 현재 고정 모델은 Stage3 wd.03/seed20261114이며 Validation .191667은 독립 성능이 아니다.
   기존 Train123/Validation12/Test8과 별개로 과거 실험 영상 합집합1,607개가 있다.
   제공 가능한 익명 원천 ID·촬영구간·중복관계로 이력과 겹치지 않는 평가 자료를 확인하고 싶다.
2. [공식 페이지](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=103)의
   v1.1/2023-12-11 라벨 수정과 보유 ZIP의 대응 버전·SHA/수정목록을 요청한다.
   공개 schema의 attributes.name은 형태소 표제어로 설명된다. 실제 지문자 철자열과의 관계,
   철자 생략·변이·복합 자모·숫자 전사 규칙을 확인받고 싶다.
3. 공개 소개의 studio20명과 CROWD21명은 서로 다른 수집 설명이다.
   real_sen의 번호를 CROWD에 적용하지 않았으므로 CROWD 전용 안정된 익명 수행자 매핑이 필요하다.
4. 설명서7969/가이드18941은 이번 공개 경로에서도 PDF를 확보하지 못했다.
   교육데이터 포털도 같은 AI-Hub 파일로 연결되므로 별도 최신 문서·정상 열람 절차를 요청한다.
5. 원래 검토519개 중 기존 실험과 겹치지 않는6개도 독립 전사/수행자/특징 계약이 미확인이다.
   검토자가 라벨 비노출 상태에서 원본 PTS 전체를 보고 완전 자모열·구간·검수 출처를 승인해야 한다.
   실명·얼굴 명부는 요청하지 않는다. 비식별 코드와 정당한 승인 근거면 된다.

## 숙련 검토자에게 인계할 기존 자료

- 기존 `review-pack-final/blind-index.html`과519개 페이지를 그대로 사용한다.
- `blind-transcription-template.csv`에 전사 단위·구간·불확실성·검토자·근거파일을 기록한다.
- 최초 전사가 고정된 후에만 기존 adjudication 파일의 제공 라벨과 대조한다.
- 일부 crop/기하 후보나 모델 예측으로 전체 전사를 승인하지 않는다. 불확실하면 UNCERTAIN을 유지한다.
- 현재6개 후보의 목록과 과거 실험1,607개 목록은 비공개 로컬 감사 결과를 참조한다.

## 새 수행자 평가 자료의 대안

제공기관이 확인한 미학습 익명 수행자 holdout을 우선 요청한다. 제공이 불가능하면 팀과
새 평가 모집·동의·고정 프롬프트·원본 PTS·2인 독립 전사/이견조정 절차를 먼저 합의한다.
이 작업에서는 실제 모집·개인정보 수집·추가 영상 다운로드를 하지 않았다.
훈련에 참여한 사람의 익명 목록조차 확인할 수 없다면 새 촬영만으로 기존 수행자 비중복을 확정할 수 없다.
추가 학습보다 수행자·전사·데이터 버전 근거 확보가 먼저다. Refs #2.
