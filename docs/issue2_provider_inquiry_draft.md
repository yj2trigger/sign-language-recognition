모델 학습에 참여하지 않은 수행자에 대한 CER와 실제 손동작·철자 정답의 일치를 검증하려고
합니다. 실명·얼굴 정보나 생체식별 정보가 아닌 안정된 비식별 코드를 요청드립니다.

현재 보유한 Validation 자료는 원본 영상 2,000개와 형태소 JSON 2,000개입니다.
별도 실험의 Train123/Validation12/Test8을 사용했으며 이 구분이 수행자 독립이라고
가정하지 않고 있습니다. CROWD 디렉터리·파일명·저장 URL을 사람 ID로 확정하지 않았습니다.

다음 자료의 존재, 공식 정의, 제공 가능 범위와 신청 절차를 안내 부탁드립니다.

1. `video_id → 비식별 performer_id` 대응표와 해당 코드가 실제 언어제공자를 구분한다는
   정의·버전·출처. 촬영자, 업로더, 라벨 작업자, 세션 ID와의 차이도 부탁드립니다.
2. 파일명의 FS 번호·CROWD 번호·F 및 `CROWD/18`, `CROWD/19` 디렉터리의 정확한 의미.
   동일 수행자의 재촬영·중복 클립·서로 겹치는 구간을 연결할 수 있는 원본 클립 ID가 있는지요?
3. 공식 split의 수행자 중복 정책과, 현재 보유 자료 외에 미학습 수행자를 평가할 수 있는
   파일명·파일 키·예상 용량. 영상 다운로드는 안내·승인 전 임의로 진행하지 않겠습니다.
4. 형태소 `data[].attributes[].name`이 실제 철자한 문자열인지, 형태소 표제어·번역인지,
   또는 다른 정규화 문자열인지. 지문자·지숫자·일반 수어를 구별하는 공식 기준도 요청합니다.
5. 영상별 독립 자모 전사, 자모 순서, 시작·종료 PTS가 제공되는지요? 복합모음·겹받침·
   쌍자음의 표현과 전사 단위, 원래 표기와 영상 철자가 다른 경우의 규칙도 부탁드립니다.
6. 형태소 start/end의 시계 기준과 첫·끝 자모 포함 정책, 제공 영상 PTS와의 대응,
   전사 검수 주체·검수 완료 여부·수정 이력 및 데이터 버전.
7. 설명서 fileSn 7969와 구축활용가이드 fileSn 18941의 정상 열람 방법 또는 최신 파일.
   현재 공개 링크 GET 응답은 200/text-html 79바이트의 접근 오류 스크립트였습니다.
   별도 로그인·이용 승인 등이 필요하다면 정상 신청 절차를 따르겠습니다.
